# noisydigital.com

Refonte du site NOISY DIGITAL (WordPress, hébergé chez Hostinger).

Ce dépôt est le thème WordPress "Noisy" lui-même : sa racine est déployée par Hostinger (intégration GitHub, branche `main`) dans `public_html/wp-content/themes/noisy/`.

- Racine : fichiers du thème (style.css, functions.php, templates, assets).
- La documentation du projet (inventaire SEO, données de trafic, plan de redirections) est conservée hors dépôt.

Le contenu (pages, articles, médias) reste dans la base WordPress ; ce dépôt ne contient que le code du thème.
